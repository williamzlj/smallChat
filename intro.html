核心功能

把沟通中的信息沉淀为可管理的记录与待办

�

碎片化信息记录

灵感、结论、提醒、重要信息随手记下，支持文字 / 图片 / 文件，配合引用与颜色标记，散落的信息有处可寻。

�

一键转待办

任何一条记录一键转为待办事项，跨项目聚合到统一面板，支持完成 / 恢复 / 归档，工作安排一目了然。

�

双重备注沉淀

公共备注团队共享、私有备注仅自己可见，给每条记录补充上下文，日后回看不再一头雾水。

🎨

四色标记分类

红 / 橘 / 蓝 / 绿四色快速分类与优先级标注，配合置顶突出关键事项，扫一眼抓住重点。

�

多端同步 · 随时查看

手机、电脑、平板数据实时同步，PWA 支持安装到桌面、离线查看，随时随地处理备忘与待办。

🔒

数据自主掌控

开源后端 PHP + SQLite，部署在自己的主机上，所有记录数据完全自己保管，无需依赖第三方平台。

� 待办事项高效流转

信息太杂容易漏事？把任何一条记录一键标记为「待办」或「重要」，自动从所有项目聚合到独立面板。完成、恢复、归档，闭环管理。

待办与四色标记联动，按颜色快速扫读优先级，效率成倍提升。

  • ✓周五前提交项目周报高优
  • ✓联系供应商确认报价
  • ✓整理会议纪要并归档待办
  • ✓复核新方案细节后同步团队

� 公共 + 私有，双重备注

每条记录可以同时附加「公共备注」和「私有备注」。公共备注由作者或管理员维护，团队全员可见；私有备注仅自己可见，用于个人备忘。

两个独立文本框同时编辑、分别保存，互不干扰，信息沉淀更安心。

🔵 公共备注（团队可见）
这份方案是项目基线，请大家以此为准。
🟢 私有备注（仅自己可见）
下周需要跟进对方的交付时间。

⚡ 信息整理快人一步

引用回复、置顶强调、多选合并转发、全文搜索——常用的整理操作都在长按菜单里，双列网格布局触手可及。

还能进入文本选择模式，精准复制记录中的任意片段。

三步上手

零门槛开始高效记录与协同

1

注册账号

打开应用，用邮箱注册一个账号。所有设备用同一账号登录即可多端同步。

2

创建协作空间

创建一个协作空间，邀请伙伴加入；也可以单独记录，作为个人备忘使用。

3

记录 → 转待办 ✨

随手记录信息，加备注、标颜色、转待办，让每一条信息都有着落。
